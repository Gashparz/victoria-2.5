TGC Treaties - extra historical treaties for TGC (The Grand Combination)
Needs: TGC and the Console Commands plugin (mod\TGCConvertPop\TGCConvertPop.dll).

Tick "TGC Treaties" in the launcher together with TGC. The plugin then reads treaties\tgc.txt:
the historical treaties of TGC's own events (Treaty of London 1839, Oregon 1846, Erzurum 1847, Jade 1853,
Chuguchak 1864, Saint Barthelemy 1877, Argentina-Chile 1881, Heligoland-Zanzibar 1890 with the East African
side, Colombia-Venezuela 1891, Carolines 1899, Petropolis 1903, ...) rewritten for the plugin's treaty system,
with TGC's tags, provinces and state regions. Entries with the same id replace the plugin's base version.

Without TGC, do not tick this mod; the plugin's base treaties (mod\TGCConvertPop\treaties\base.txt)
work with vanilla and any other mod.

TGC's original events stay in the game. Whichever happens first wins: once the provinces have changed
hands, the other one no longer applies.
