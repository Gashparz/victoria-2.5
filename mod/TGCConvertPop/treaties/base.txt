# Historical treaties for the Console Commands plugin (TGCConvertPop.dll). Works with any mod or none.
# A treaty fires inside its years when the world allows it: a "from" country owns at least one of the
# listed provinces, a "to" country exists, they are not at war. Provinces the giver no longer owns are skipped.
#
#   id        unique name (a later file with the same id replaces this entry, e.g. a mod's own version)
#   years     { first last }
#   kind      cession | swap | population
#   from, to  candidate tags, first one that qualifies is used
#   provinces / regions / cores_of   what FROM gives (regions come from the active map's region.txt;
#             cores_of = FROM's provinces that are cores of these tags)
#   back / back_regions / back_cores_of   what TO gives in return (swap)
#   to_owns   TO must own one of these provinces
#   majority  yes = a province moves only if TO's nation is its majority (plebiscites)
#   chance    percent per month inside the window
#   source    where the treaty comes from (vanilla event, TGC event, history)
